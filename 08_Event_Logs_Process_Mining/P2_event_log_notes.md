# Role D P2 Event Log Notes

This file explains the simulated P2 housing subsidy event log generated by `housing-service/scripts/generate_p2_event_log.py`.

## Log Fields

| Field | Description |
|---|---|
| case_id | Unique process instance ID. |
| process_name | Name of the BPMN process. |
| activity | Activity name aligned with P2 BPMN tasks. |
| timestamp | ISO timestamp of the event. |
| resource | Responsible role or system component. |
| outcome | Event result, such as approved, failed, requested or notified. |
| service_name | Related business service name. |

## Simulated Variants

The log covers direct approval, supplementary document approval, multiple supplementary document loops, employment verification failure, housing verification failure, general ineligibility, review delay, parallel verification order difference, and incomplete document rejection.

## Process Mining Use

The CSV can be imported into PM4Py or ProM after mapping `case_id` as case identifier, `activity` as activity, and `timestamp` as timestamp. It can support process discovery, variant analysis, loop analysis and bottleneck analysis.
